## Batch Prompting Tips

1. **Consistency pass:** generate all idle states in one session, then all working states in another. This helps maintain style coherence within each state category.

2. **Industry batch:** generate all buildings within one industry group together before moving to the next. This reinforces the industry color identity.

3. **Silhouette test:** after generating, shrink each result to 48x48px and check if you can still tell which building it is. If not, the shape needs more contrast.

4. **State contrast test:** place idle and working versions side by side. The working version should be obviously more active — brighter, more saturated, with visible motion cues. If they look too similar, push the working state harder.

5. **Color identity test:** lay out one building from each industry at the same scale. Each should read as a distinct color family. Adjust if two industries are too close in hue.

6. **Extractor vs processor test:** extractors (camps, pits, quarries, wharfs, mines, farms) should look open and raw. Processors (mills, workshops, smiths) should look enclosed and refined. If an extractor looks too building-like, open it up. If a processor looks too raw, add walls and a roof.

7. **Background removal:** most generators will produce backgrounds. Run through background removal (rembg, remove.bg, or manual masking) and verify clean alpha edges before exporting.

8. **Post-processing:** after generation, normalize all outputs to 128x128, center the building, ensure ground contact is at the bottom 15% of the canvas, and export as PNG-32 with full transparency.
