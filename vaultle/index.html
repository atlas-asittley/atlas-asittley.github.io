About Vaultle — the daily code-cracking game

Vaultle is a free daily code-breaking puzzle based on the classic game of Bulls & Cows (also known as Mastermind). Every day there's one hidden 4-digit code — all four digits are different — and the same code is shared by every player. Your goal is to crack it in nine guesses.

After each guess you get two clues: the number of bulls (a correct digit in the correct position) and cows (a correct digit in the wrong position). Use those clues to deduce the code, then share your spoiler-free result grid. A brand-new code drops every day.

How to play

  1. Tap four different digits (0–9) to enter a guess, then press Guess.
  2. 🎯 Bulls = right digit, right spot. ◐ Cows = right digit, wrong spot.
  3. No color tells you which digit is which — that's the deduction!
  4. Get four bulls within nine guesses to crack the vault.

FAQ

Is Vaultle free? Yes — free, no ads, no login. Optional tips support development.

How often are there new puzzles? A new code every day, the same for everyone, reset at midnight UTC.

What's the difference from Wordle? Same daily, shareable format, but you crack a number code using bulls & cows logic instead of guessing a word.
