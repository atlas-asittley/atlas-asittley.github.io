Sip Timer

A repeating vibration nudge to drink water.

Install it on your phone

  1. Open this page on the phone itself and tap Download. Chrome will warn that this file type can harm your device — tap Download anyway.
  2. Tap the downloaded file (or open Files → Downloads and tap it).
  3. Android will say the source isn't allowed. Tap Settings on that prompt, then turn on Allow from this source for the app you're installing from — usually Chrome or Files. Then go back.
  4. Tap Install. If Play Protect warns about an unknown developer, choose Install anyway — that's expected for a self-signed app.

The permission lives at Settings → Apps → Special app access → Install unknown apps if you'd rather set it beforehand.

First run — grant these three

  • Notifications — asked on launch. The ongoing notification is the running UI, so this one is mandatory.
  • Alarms & reminders — opens when you first tap Start. Without it the buzz drifts late in Doze.
  • Battery: Unrestricted — also prompted at Start. This is what keeps it firing with the screen locked.

How it works

  • Pick an interval (1–30 min, default 5) and tap Start.
  • Every interval it gives five short buzzes — no sound — then restarts the countdown on its own.
  • The notification counts down live and carries Reset, Pause, and Stop. All three work straight from the lock screen, one tap, no unlock.
  • Reset restarts the full interval early — for when you drink before the buzz.
  • The app screen keeps a tally of buzzes fired today; it clears at midnight.
Not buzzing? It's almost always the battery setting in step 3 above — set the app to Unrestricted and it'll fire with the screen locked.
